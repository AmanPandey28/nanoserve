# Nanoserve

A lightweight LLM serving engine to serve models locally or consumer GPUs. I'll be trying to have this engine serve different architectures from dense, MoE, Linear and TTS, STT, diffusion and vision language models. Add CUDA, Triton, CuTe kernels and keep experimenting, profiling and continulously improve this engine.

I will add more details as I keep working on the project.
